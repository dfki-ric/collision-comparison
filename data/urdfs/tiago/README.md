# TIAGo

Collision model of PAL Robotics' TIAGo with the Hey5 hand for the self-collision benchmark `tiago_self_collision`
(generated by `compare-python/test_file/from_tiago_self_collision.py`). Apache License 2.0 (see [LICENSE](LICENSE)).

- `tiago.urdf` and `meshes/`: `robots/tiago_description/robots/tiago.urdf` from
  [example-robot-data](https://github.com/Gepetto/example-robot-data) (commit
  78b6101a6387de721316b0db717351d899f97b4f), which is derived from
  [tiago_robot](https://github.com/pal-robotics/tiago_robot). Modifications: the visual elements are removed, the
  Collada collision meshes are converted to STL, and the mesh paths are relative to this directory.
- `disable_collisions.srdf`: link pairs that are excluded from the self-collision checks, from PAL's collision
  blacklist (example-robot-data) and the pairs that
  [tiago_moveit_config](https://github.com/pal-robotics/tiago_moveit_config) disables as adjacent or colliding in
  the default configuration (see the comment in the file). `compare-python/src/load_tiago.py` additionally excludes
  links of the same rigid body, parent and child, and links of the same limb (hand; base and torso).
